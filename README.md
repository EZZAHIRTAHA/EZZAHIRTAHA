## Taha Ezzahir

Backend engineer at **[Cosmic DATA](https://github.com/cosmic-data)**, working on the platform side of multi-channel social and local-listing management — publishing, reviews, and analytics across the major networks.

Most of what I build is a translation layer. One button labelled *"Publish"* has to become a fistful of vendor APIs that each hold a different opinion about what a post is, what counts as an image, and how a date should be written. Reconciling those opinions is the actual work; the button is the easy part.

### Stack

**PHP 8.4** · Symfony · API Platform · Doctrine · Symfony Messenger
**MySQL** · Redis · Docker · AWS · Kubernetes

Async by default: anything that touches a third-party API goes on a queue and reports back when it's done. Third-party APIs are not to be trusted with your request/response cycle.

### Here

Mostly **PHP**, with a solid **JavaScript / TypeScript** side. Integration plumbing, API backends, and the occasional thing built purely to find out whether it would work.
